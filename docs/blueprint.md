# **App Name**: Proje4006 Assistant

## Core Features:

- AI-Powered Text Transformation: Paste text, and the tool automatically transforms it into TÜBİTAK 4006 format. The tool will ensure that it creates original, and feasible contents.
- Automatic Section Assignment: Automatically assigns pasted text to the appropriate sections: Amaç (Purpose), Yöntem (Method), Beklenen Sonuç (Expected Result), and Proje Bilgileri (Project Information). The tool will try its best to detect which of these named sections in English or Turkish, that your input text aligns with best, but make no guarantees. Please check carefully.
- AI Content Generation and Optimization: AI generates and optimizes content for each section (Purpose, Method, Expected Result) while respecting word limits, focusing on originality and feasibility.
- Document Export: Enables the project to be exported to common document formats Word and PDF.
- Project Information Input: Input fields for Proje Adı (Project Name), Araştırma Ana Alanı (Research Main Field), Tematik Konu (Thematic Subject), Danışman Öğretmen (Advisor Teacher), and Öğrenciler (Students).
- Uygunluk Puanları (Suitability Scores): Dynamically provides feedback metrics such as Özgünlük (Originality), Format Uygunluğu (Format Suitability), Dil & Anlatım (Language & Expression), and Genel Uygunluk (General Suitability).

## Style Guidelines:

- Primary color: Light blue (#A7D1F3) to give a feeling of clarity.
- Background color: Off-white (#F4F6F8) to be unobtrusive, allowing the content to stand out.
- Accent color: Soft green (#90EE90) for positive feedback, like meeting originality standards or the word count.
- Body and headline font: 'Inter', sans-serif, providing a modern, machined, objective look for optimal readability in an educational context.
- Minimalist line icons to represent different project sections and actions (e.g., AI transformation, download). Icons should be in the primary color.
- Clean, sectioned layout with clear headings for each part of the project information. The input fields should be well-spaced and easy to fill.
- Subtle animations on text transformation and score updates. A loading animation during content generation should indicate background operations.
